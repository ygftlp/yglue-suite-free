## 系统架构概览

YGFlow Suite 是一个基于微服务架构的流程编排系统，由多个核心组件构成：编排器服务（Orchestrator）、运行时引擎（Runtime）、前端UI和IDEA插件。系统采用Spring Boot作为基础框架，通过Maven进行模块化管理。

```mermaid

end

end
subgraph "开发工具"

end

```

## 数据流与执行流程

### 用户操作到编排器的数据流

当用户在前端界面进行操作时，数据通过REST API流向编排器服务。前端通过`client.ts`中的API客户端发送请求，编排器的`FlowController`接收并处理这些请求。

```mermaid
sequenceDiagram
participant 用户界面
participant API客户端
participant FlowController
participant FlowService
用户界面->>API客户端 : 保存流程配置
API客户端->>FlowController : POST /api/projects/{projectKey}/flows
FlowController->>FlowService : 调用saveFlow方法
FlowService-->>FlowController : 返回FlowVersion
FlowController-->>API客户端 : 返回成功响应
API客户端-->>用户界面 : 更新UI状态
```

**图示来源**
- [client.ts](file://apps/ygflow-orchestrator-ui/src/api/client.ts)
- [FlowController.java](file://yglue-orchestrator/src/main/java/org/yglue/flow/orch/web/controller/FlowController.java)

### 运行时引擎执行流程

运行时引擎的执行流程从接收请求开始，经历节点注册、上下文创建、节点执行和事件发布等阶段。

```mermaid
flowchart TD
Start([接收执行请求]) --> CreateContext["创建NodeExecutionContext"]
CreateContext --> RegisterNodes["注册节点执行器"]
RegisterNodes --> ExecuteNode["执行节点"]
ExecuteNode --> CheckType{"节点类型?"}
CheckType --> |REST| ExecuteREST["调用REST接口"]
CheckType --> |Service| ExecuteService["调用服务方法"]
CheckType --> |Transformer| ExecuteTransformer["执行Transformer"]
ExecuteREST --> PublishEvent["发布NodeFinishedEvent"]
ExecuteService --> PublishEvent
ExecuteTransformer --> PublishEvent
PublishEvent --> End([返回执行结果])
ExecuteNode --> Error{"发生异常?"}
Error --> |是| PublishError["发布NodeErrorEvent"]
PublishError --> End
```

**图示来源**
- [ErrorResponseFormat.java](file://yglue-runtime/src/main/java/org/yglue/flow/runtime/core/definition/ErrorResponseFormat.java)

### 预设错误格式

系统提供了三种预设的错误响应格式：

1. **标准格式 (STANDARD)**: `{errorCode, message, data}`
2. **简化格式 (SIMPLE)**: `{code, message}`
3. **中文格式 (CHINESE)**: `{错误码, 错误信息, 参数名, 详情}`

通过`ErrorResponseFormat.fromPreset("standard")`等方法可以获取预设格式实例。

### Transformer执行流程

```mermaid
flowchart TD
Start([开始执行]) --> InitState["初始化ExecutionState"]
InitState --> LoopSteps["遍历所有步骤"]
LoopSteps --> GetStep{"获取当前步骤"}
GetStep --> CheckType{"步骤类型?"}
CheckType --> |Field| ExecuteField["执行字段映射"]
CheckType --> |Object| ExecuteObject["执行对象创建"]
CheckType --> |Collection| ExecuteCollection["执行集合处理"]
CheckType --> |Condition| ExecuteCondition["执行条件判断"]
CheckType --> |Script| ExecuteScript["执行脚本"]
ExecuteField --> UpdateState["更新状态"]
ExecuteObject --> UpdateState
ExecuteCollection --> UpdateState
ExecuteCondition --> UpdateState
ExecuteScript --> UpdateState
UpdateState --> CheckNext{"还有更多步骤?"}
CheckNext --> |是| LoopSteps
CheckNext --> |否| ReturnResult["返回执行结果"]
ReturnResult --> End([结束])
ExecuteCondition --> EvalCondition["评估条件表达式"]
EvalCondition --> ConditionTrue{"条件为真?"}
ConditionTrue --> |是| ExecuteIf["执行if分支"]
ConditionTrue --> |否| ExecuteElse["执行else分支"]
ExecuteIf --> UpdateState
ExecuteElse --> UpdateState
```
