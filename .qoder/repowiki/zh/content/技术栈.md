## 简介
YGFlow Suite 是一个集流程编排、规则执行与可视化开发于一体的综合技术套件。本技术栈文档系统性地阐述了项目所依赖的核心技术体系，涵盖后端框架、前端框架、流程引擎、脚本语言及开发工具链。通过分析各技术组件的角色与集成方式，为开发者理解系统架构、进行二次开发或问题排查提供坚实的技术依据。

## 后端技术栈

### Spring Boot 3.3.4：核心应用框架
Spring Boot 3.3.4 作为 YGFlow Suite 的核心后端框架，为整个套件提供了坚实的基础支撑。它通过自动配置（Auto-Configuration）和起步依赖（Starter Dependencies）极大地简化了基于 Spring 的应用开发。在 `pom.xml` 文件中，项目明确继承了 `spring-boot-starter-parent` 3.3.4 版本，确保了依赖版本的统一管理。该框架不仅负责构建 RESTful API 接口（如 `yglue-orchestrator` 模块），还提供了依赖注入、事务管理、安全控制等企业级功能。其与 Spring MVC 的集成使得 `FlowDispatchInterceptor` 和 `FlowOrchestratedAspect` 等拦截器和切面能够无缝工作，实现了对流程调用的统一调度与监控。

### MyBatis 3.0.3：数据持久化层
MyBatis 3.0.3 在 YGFlow Suite 中承担着数据持久化的关键角色，负责将 Java 对象与数据库表进行映射。在 `yglue-orchestrator` 模块的 `pom.xml` 中，`mybatis-spring-boot-starter` 3.0.3 版本被明确引入，实现了与 Spring Boot 的完美集成。该项目采用 XML 映射文件的方式定义 SQL 语句，`application.yml` 配置文件中的 `mybatis.mapper-locations` 指向了 `classpath*:mapper/**/*.xml`，确保了所有 Mapper XML 文件能被正确加载。通过 `FlowMapper`、`ProjectMapper` 等接口与对应的 `FlowMapper.xml` 文件，系统实现了对流程定义、项目元数据等核心信息的高效增删改查操作。

### LiteFlow 2.12.1：流程编排引擎
LiteFlow 作为 YGFlow Suite 的流程编排引擎，是实现复杂业务流程动态编排的核心。尽管 `yglue-runtime` 模块引入的是 LiteFlow 2.15.0 版本，但其设计理念与 2.12.1 版本一脉相承。系统通过 `LiteFlowRuleEngine` 类将自定义的 `FlowDefinition` 转换为 LiteFlow 能够识别的规则（如 XML 格式），并利用 `FlowExecutor` 执行器来驱动流程的流转。`FlowDefinitionToLiteFlowConverter` 负责转换逻辑，而 `NodeExecutorRegistry` 则注册了 `log`、`delay`、`if`、`branch`、`service` 等多种节点执行器，赋予了流程强大的扩展能力。这种集成方式使得流程的定义、加载和执行完全解耦，支持了动态更新和热加载。

## 开发工具与构建系统

### IntelliJ Platform SDK、Gradle 8.x 与 Maven 3.8+
YGFlow Suite 的开发工具链体现了对多构建系统的支持。`yglue-idea-plugin` 模块使用 Gradle 8.x 作为构建工具，其 `build.gradle.kts` 文件明确应用了 `org.jetbrains.intellij` 插件，并指定了 `version.set("2024.2")`，这表明该插件是基于 IntelliJ Platform SDK 为特定版本的 IntelliJ IDEA 开发的。而套件的其他核心模块（如 `yglue-orchestrator`、`yglue-runtime`）则采用 Maven 3.8+ 进行构建，通过 `pom.xml` 文件管理依赖和构建生命周期。这种分工明确：Gradle 用于开发 IDE 插件，利用其灵活的 DSL 和对 IntelliJ SDK 的良好支持；Maven 则用于构建稳定的后端服务和运行时库，保证了依赖管理和构建过程的标准化与可重复性。

## 技术协同与架构集成
YGFlow Suite 的各项技术协同工作，构成了一个分层清晰、职责分明的完整架构。后端以 **Spring Boot** 为基石，通过 **MyBatis** 管理持久化数据，并利用 **LiteFlow** 实现流程的动态编排。**Groovy** 脚本引擎为流程节点注入了强大的动态逻辑能力。前端则以 **Vue 3** 和 **TypeScript** 构建响应式用户界面，通过 **Vue Flow** 实现流程的可视化编辑，并借助 **Monaco Editor** 提供专业的代码编辑体验。前后端通过 REST API 进行通信，Vite 作为构建工具优化了前端资源。开发层面，**Maven** 统一管理后端模块的构建，而 **Gradle** 和 **IntelliJ Platform SDK** 则专门用于开发功能强大的 IDE 插件。这种技术选型和集成方式，使得 YGFlow Suite 既具备了企业级应用的稳定性，又拥有了高度的灵活性和可扩展性。

## 总结
YGFlow Suite 的技术栈是一个精心设计的生态系统。后端技术栈以 Spring Boot 为核心，MyBatis、LiteFlow 和 Groovy 各司其职，共同支撑起强大的流程编排与执行能力。前端技术栈采用 Vue 3 + TypeScript 的现代组合，结合 Vue Flow 和 Monaco Editor，提供了卓越的可视化开发体验。构建和开发工具方面，Maven 和 Gradle 的分工协作，确保了不同模块的高效开发与集成。全面理解这些技术的角色与协同方式，是有效使用、二次开发和维护 YGFlow Suite 的关键。
