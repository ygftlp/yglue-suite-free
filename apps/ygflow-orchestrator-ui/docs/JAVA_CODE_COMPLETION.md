# 脚本编辑器提示能力说明

## 当前状态

脚本编辑器基于 CodeMirror 构建，但已经调整为按需加载:

- 只有在用户点击“打开编辑器”后，编辑器运行时才会异步加载
- Studio 页面首次进入时不再同步带入整套编辑器依赖
- 编辑器加载失败时会展示错误提示，并支持重试

## 当前支持的提示能力

### 1. 上下文变量提示

支持以下常用变量:

- `ctx`
- `input`
- `output`
- `resolved`
- `request`

其中 `request` 会结合端点 Schema 自动补全:

- `path.xxx`
- `query.xxx`
- `body.xxx`
- `headers`

### 2. 项目类引用提示

编辑器会通过后端接口拉取项目元数据，并提供:

- 依赖坐标提示
- 项目类引用提示
- `import xxx.yyy.ClassName` 补全

### 3. 上游输出类型成员提示

当上游节点输出类型可识别且不是简单类型时，编辑器会动态加载:

- 字段列表
- 方法列表

这部分数据同样来自后端接口，适合业务项目做定制化增强。

### 4. 右侧提示面板

编辑器右侧保留“变量 / 函数”面板，支持:

- 点击插入片段
- 展示描述信息
- 展示方法参数或额外 tooltip

## 实现说明

核心实现位于:

- `src/components/ScriptEditor.vue`

当前实际使用的 CodeMirror 依赖只有:

- `@codemirror/state`
- `@codemirror/view`
- `@codemirror/commands`
- `@codemirror/autocomplete`

不再保留未使用的语法高亮和 lint 相关依赖，避免仓库内容与真实实现脱节。

## 已知边界

当前编辑器重点是业务提示和项目类补全，因此:

- 还没有启用完整的 Java / Groovy 语法高亮
- 还没有做静态类型检查
- 还没有做方法参数级别的智能推断

如果后续业务侧确实需要更强的脚本开发体验，再按需增加语法高亮、lint 或语言服务会更合适。

## 快捷键

- `Ctrl + S` / `Cmd + S`: 保存并关闭编辑器
