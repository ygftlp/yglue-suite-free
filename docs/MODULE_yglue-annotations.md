# yglue-annotations 模块文档

## 模块概述

`yglue-annotations` 是 YGFlow Suite 的注解定义模块，提供了用于标记和描述业务流程相关组件的 Java 注解。该模块是其他所有模块的基础依赖，定义了整个系统的元数据标注规范。

## 模块职责

- **注解定义**：提供用于标记 Flow API、Flow Model、Flow Resolver 等组件的注解
- **元数据规范**：定义组件元数据的标准结构，确保各模块间数据格式一致
- **编译时标记**：为编译时处理和运行时识别提供标记接口

## 核心能力

### 1. FlowApi 注解
用于标记业务服务类，标识该类是一个可被流程编排调用的服务。

**主要属性：**
- `name`: 服务显示名称
- `description`: 服务描述
- `version`: 服务版本号
- `beanName`: Spring Bean 名称（可选）

### 2. FlowModel 注解
用于标记数据模型类，标识该类是一个流程中使用的数据传输对象。

**主要属性：**
- `name`: 模型显示名称
- `description`: 模型描述
- `category`: 模型分类

### 3. FlowResolver 注解
用于标记参数解析器类，标识该类是一个自定义的参数解析器实现。

**主要属性：**
- `type`: 解析器类型标识
- `name`: 解析器显示名称
- `description`: 解析器描述
- `category`: 解析器分类

### 4. FlowOperation 注解
用于标记服务方法，标识该方法是一个可被流程调用的操作（已废弃，当前使用 FlowApi 的 operations 配置）。

## 技术特性

- **零依赖**：该模块不依赖任何第三方库，保持轻量级
- **编译时友好**：注解设计简洁，适合编译时处理和 IDE 插件扫描
- **运行时兼容**：注解信息可通过反射获取，支持运行时动态识别

## 使用场景

1. **IDE 插件扫描**：IntelliJ IDEA 插件通过扫描这些注解，自动生成元数据
2. **运行时识别**：运行时引擎通过反射读取注解信息，进行组件识别和调用
3. **元数据管理**：Orchestrator 服务通过注解信息构建和管理组件元数据

## 依赖关系

- **被依赖模块**：
  - `yglue-runtime`: 运行时引擎需要读取注解信息
  - `yglue-orchestrator`: 编排器服务需要解析注解元数据
  - `yglue-idea-plugin`: IDE 插件需要扫描注解

- **依赖模块**：无（零依赖模块）

## 构建与打包

- **打包方式**：JAR
- **Maven 坐标**：`org.yg:yglue-annotations:0.1.0-SNAPSHOT`
- **源码打包**：自动生成 `-sources.jar` 文件

## 版本兼容性

- **Java 版本**：Java 17+
- **注解保留策略**：运行时保留（`@Retention(RetentionPolicy.RUNTIME)`）

## 扩展性

该模块设计为可扩展的注解体系，未来可以添加：
- 流程节点注解
- 数据转换器注解
- 验证器注解
- 事件监听器注解

## 注意事项

1. 注解属性应保持向后兼容，避免破坏现有代码
2. 新增注解时需要考虑 IDE 插件的扫描能力
3. 注解的默认值应合理，避免强制要求所有属性
