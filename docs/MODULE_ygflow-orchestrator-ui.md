# ygflow-orchestrator-ui 模块文档

## 模块概述

`ygflow-orchestrator-ui` 是 YGFlow Suite 的可视化设计台前端模块，基于 Vue 3 + TypeScript 构建，提供流程编排、节点配置、规则预览等可视化能力。该模块是流程设计的主要入口，为业务人员和技术人员提供友好的流程设计体验。

## 模块职责

- **流程设计**：提供拖拽式流程设计画布，支持节点添加、连接、配置
- **节点配置**：提供节点属性配置面板，支持参数设置、验证规则配置
- **流程设置**：提供流程全局设置面板，支持入口点配置、响应格式配置
- **版本管理**：提供流程版本列表和版本切换功能
- **规则预览**：提供 LiteFlow 规则预览功能
- **数据转换编辑**：提供 Transformer DSL 可视化编辑器

## 核心能力

### 1. 流程设计画布

**核心组件：**
- `CanvasEditor`: 画布编辑器主组件
- `CanvasSurface`: 画布表面组件（基于 Vue Flow）
- `CanvasPalettePanel`: 组件面板
- `CanvasInspectorPanel`: 属性检查器面板
- `CanvasToolbar`: 工具栏

**主要功能：**
- 拖拽添加节点
- 节点间连线
- 节点选择和移动
- 画布缩放和平移
- 网格背景显示
- 小地图导航

### 2. 节点类型支持

**支持的节点类型：**
- `entry`: 入口节点
- `exit`: 出口节点
- `service`: 服务节点
- `transformer`: 转换节点
- `branch`: 分支节点
- `transaction`: 事务节点

**节点配置能力：**
- 服务节点：选择服务、方法、参数配置、验证规则
- 转换节点：Transformer DSL 编辑
- 分支节点：条件表达式配置
- 事务节点：事务类型配置（begin/end）

### 3. 参数配置

**核心组件：**
- `Inspector`: 属性检查器
- `ValidationEditor`: 验证规则编辑器

**主要功能：**
- 输入参数配置（参数名、类型、来源、默认值）
- 验证规则配置（必填、类型、长度、范围、正则、表达式等）
- 对象字段验证配置
- Groovy 脚本编辑器集成

### 4. 流程设置

**核心组件：**
- `FlowSettingsPanel`: 流程设置面板

**主要功能：**
- 流程基本信息（名称、代码、描述）
- REST 入口点配置（路径、方法、Schema）
- 数据响应格式配置（标准格式、自定义格式）
- 自定义字段配置

### 5. 版本管理

**核心组件：**
- `VersionList`: 版本列表组件

**主要功能：**
- 版本列表展示
- 版本加载（查看历史版本）
- 版本发布（保存并发布为新版本）
- 版本信息展示（版本号、发布时间、创建者）

### 6. 规则预览

**核心组件：**
- `useRulePreview`: 规则预览组合式函数

**主要功能：**
- LiteFlow 规则生成
- 规则文本预览
- 规则导出

### 7. 数据转换编辑

**核心组件：**
- `TransformerEditor`: Transformer 编辑器

**主要功能：**
- Transformer DSL 可视化编辑
- 字段映射配置
- 集合处理配置
- 条件转换配置
- Groovy 脚本编辑

## 技术特性

### 1. Vue 3 Composition API
- 使用 Composition API 组织代码
- 响应式数据管理
- 组合式函数复用

### 2. Vue Flow
- 基于 Vue Flow 实现流程图
- 支持节点拖拽、连线、缩放
- 支持自定义节点样式

### 3. Monaco Editor
- 集成 Monaco Editor 提供代码编辑能力
- 支持 Groovy 语法高亮
- 支持代码补全和错误提示

### 4. CodeMirror
- 集成 CodeMirror 提供轻量级代码编辑
- 支持 Transformer DSL 编辑

### 5. TypeScript
- 全面使用 TypeScript 提供类型安全
- 类型定义完善，减少运行时错误

### 6. Vite
- 使用 Vite 作为构建工具
- 快速的开发服务器
- 优化的生产构建

## 使用场景

1. **流程设计**：业务人员和技术人员协作设计业务流程

3. **流程发布**：保存草稿和发布流程版本
4. **版本管理**：查看历史版本和回滚到历史版本

## 构建与部署

### 开发环境
```bash
cd apps/ygflow-orchestrator-ui
npm install
npm run dev
```

### 生产构建
```bash
npm run build
```

构建产物在 `dist` 目录，可部署到任何静态文件服务器。

### 部署建议
- 使用 Nginx 或 Apache 作为 Web 服务器
- 配置 API 代理，解决跨域问题
- 启用 Gzip 压缩，提升加载速度

## 版本兼容性

- **Node.js 版本**：18.x+
- **浏览器版本**：Chrome 110+, Firefox 110+, Safari 16+
- **Vue 版本**：3.5.x
- **TypeScript 版本**：5.6.x

## 注意事项

1. 流程内容需要定期保存，避免数据丢失
2. 节点配置需要验证合法性，避免运行时错误
3. 版本发布前建议预览规则，确保规则正确
4. 浏览器兼容性需要注意，建议使用现代浏览器
5. 大量节点时可能影响性能，建议优化流程结构
